Connect an agent (MCP)

Endpoint: {{ base }}/mcp (streamable HTTP), with Authorization: Bearer <token>. Give most agents a read token, and a write token to those that save things.

Claude Code:

claude mcp add --transport http alexandria {{ base }}/mcp --header "Authorization: Bearer $ALEXANDRIA_TOKEN"

JSON configuration:

{"mcpServers": {"alexandria": {"type": "http", "url": "{{ base }}/mcp", "headers": {"Authorization": "Bearer ${ALEXANDRIA_TOKEN}"}}}}

REST API: {{ base }}/api/v1 — interactive docs.
